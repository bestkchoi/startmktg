# 1. Purpose
START MKTG 플랫폼에서 캠페인을 생성할 때, 매체별로 지원하는 목적과 채널이 다르기 때문에


# 2. 주요 기능
## 2-1. Media 생성
- START MKTG가 제공하는 기본 미디어 목록은 고정이며, 필요 시 시스템 업데이트로만 변경된다.


## 2-2. 제공되는 Media 예시
- Google Ads
- Meta Ads
- Kakao Moment
- Naver Search Ads
- Youtube
- TikTok Ads
- CRM (SMS, Kakao Message, Email 등)



# 3. 사용자 흐름
1. Start Campaign 생성화면에서 Media를 선택한다.
2. Media 선택 시 해당 미디어에 맞는 필수 입력값이 자동으로 설정된다.
3. 사용자는 미디어 정보를 입력하고 저장한다.
